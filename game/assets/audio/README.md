# Wrong Floor runtime audio

This pass removes the previous layered horror soundscape. Recorded source material owns the horror cues; procedural audio is limited to quiet elevator machinery.

Runtime mapping:

- `music-box.ogg` ← `OpenDoorMusicBox.wav`: a calm ten-second source excerpt loops continuously. It is about 6.25× louder with the doors fully open than fully closed.
- `heartbeat.ogg` ← `688735__cloud-10__heartbeat-97-bpm.wav`: loops while a monster is visible and subtly accelerates as threat pressure rises.
- `scared-breathing.ogg` ← `ScaredBreathing.wav`: low panic breathing while a monster is visible.
- `shaky-breaths.ogg` ← `213293__aderumoro__shaky-breaths-frightened-scared-young-lady-girl-teenager.wav`: crossfades in as threat pressure becomes severe.
- `bones.ogg` ← `656055__nayahnaidoo__stepping-on-bones-with-crunching-owi.wav`: one-shot when the monster begins its final approach.
- `somebody-please.ogg` ← `405643__deleted_user_5620050__somebody-please.mp3`: one restrained clue cue per run.
- `jumpscare.ogg` ← `Jumpscare.wav`: begins at final approach and controls the intrusion result hold.
- `scream.ogg` ← `239902__thesubber13__scream-3.ogg`: one-shot at actual intrusion death.

All runtime files are compact Opus derivatives cut directly from the supplied originals. `ClosedHorrorSound.wav` and the previously rejected asylum-entrance clip are intentionally absent.
